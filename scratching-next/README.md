# Scratching Next

A Next.js app built to practice Next.js fundamentals. Displays a student directory using a reusable StudentCard component with Props, across a Home page and an About page.

## How to run

```bash
cd scratching-next
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.

## What's inside

- `src/pages/index.js` — Home page with student list
- `src/pages/about.js` — About page
- `src/components/StudentCard.js` — reusable card component
- `src/styles/` — CSS modules for each page and component

## Topics Covered

- Next.js Pages & Routing
- Reusable Components
- Props
- CSS Modules
- Link Navigation
