# Scratching

This repo contains two projects built to practice React and Next.js fundamentals.

```
scratching/
├── Scratching-react/    → Vite + React (Tasks 2–6)
└── scratching-next/     → Next.js (Student Directory)
```

---

## Scratching React

A Vite + React app covering JSX, components, props, state, hooks, and local storage — all on a single page.

### How to run

```bash

npm install
npm run dev
```

### Topics Covered

- JSX, Rendering Elements, Nested Elements, Attributes, Comments
- Functional Components
- Rest & Spread Operators
- Props
- useState (String, Number, Boolean, Array, Object)
- useEffect & Local Storage
